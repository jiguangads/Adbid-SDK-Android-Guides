# JAdbid SDK 集成文档（总览）

JAdbid Android SDK 当前发版包只输出标准包。后续更新集成说明时，请以标准包专题文档为主，本文仅作**入口与导航**。

| 文档 | 产物 | 适用场景 |
|------|------|----------|
| **[INTEGRATION_GUIDE_STANDARD.md](./INTEGRATION_GUIDE_STANDARD.md)** | `jadbid-android-{version}-release.aar` + 插件 AAR + **自行声明**各广告渠道 Maven 依赖 | 需要控制体积、版本或与宿主依赖对齐 |

**维护约定**

- **标准包**：更新 **`docs/INTEGRATION_GUIDE_STANDARD.md`**（与 `ad-example`、`build-all.sh` 产出的 standard 产物一致）。  
- **Maven 仓库地址**：与仓库根目录 **`build.gradle`** 中 **`allprojects { repositories { ... } }`** 保持同步（标准包专题文档 §3 已收录）。  
- 本文件 **`INTEGRATION_GUIDE.md`** 仅在产物策略或导航结构变化时修改。

---

## 快速说明

| 项目 | 标准包 |
|------|--------|
| 主 AAR | `jadbid-android-*.aar` |
| 渠道三方 SDK | 宿主 `build.gradle` 自行 `implementation` |
| minSdk | **23**（与仓库各模块 Gradle 一致） |
| Manifest | 需按所接渠道补充（若接 AdMob 需配置 `APPLICATION_ID` 等） |
| 参考工程 | **`ad-example`** / **`example/standard`** |
